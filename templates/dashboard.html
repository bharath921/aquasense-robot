ESP8266 setup
  1. Set your Wi-Fi credentials in the Arduino sketch.
  2. Point the sketch at http://<computer-LAN-IP>:<Flask-port>/data and send JSON with POST.
  3. Install the ESP8266 board package, ArduinoJson, and the DHT library, then flash the sketch.
  4. Open the Serial Monitor at 115200 baud to check the connection.
